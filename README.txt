15 COMPLETE WEB DEVELOPMENT PRACTICALS

Every browser-based practical has separate HTML, CSS, and JavaScript files.
React practicals have index.html, src/main.jsx, src/App.jsx, and src/style.css.
Node/Express practicals have app.js plus public/index.html, public/style.css, and public/script.js when a browser interface is needed.

HTML/CSS/JS practicals (01-06): Open each folder's index.html in a browser, or use VS Code Live Server.

React practicals (07-10):
- Install Node.js.
- In a new Vite React project, copy the practical's index.html, src/main.jsx, src/App.jsx, and src/style.css.
- Run npm install and npm run dev.

Node/Express practicals (11-15):
- Install Node.js.
- In the practical folder run npm init -y.
- For Express folders run npm install express.
- Run node app.js and open http://localhost:3000.

Educational examples only: no database or production authentication; demo data may reset when the server restarts.
